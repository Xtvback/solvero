# SOLVERO — projeto musical principal

Este é o **repositório oficial e principal** do universo musical SOLVERO de André M. Fernandes, incluindo o site/arquivo das sub-bandas e dos respetivos álbuns.

- Repositório: https://github.com/Xtvback/solvero
- Site (GitHub Pages): https://xtvback.github.io/solvero/
- Biblioteca de referência na Google Drive: [Solvero](https://drive.google.com/drive/folders/1FHP64hZ5ydzE0nOv8g44vWj1_lHg_g19)
- Capa/arquivos do projeto principal na subpasta: [Solvero / Solvero](https://drive.google.com/drive/folders/1YDtJ848YTbLnMxiBmA8eHFj1H_Gr27Vc)

- **Atlântico Lusitano** — segundo álbum *O Código*
- **Dosis Perfecta** — existe uma segunda capa/segundo álbum; confirmar título antes de atribuir nome definitivo

As sub-bandas e as suas capas devem ser confrontadas com as respetivas pastas na biblioteca da Drive. Nunca assumir que a segunda capa é uma substituição da primeira: apresentar os álbuns separadamente e em ordem cronológica.

## Direção de desenvolvimento

Este repositório é a referência para futuras atualizações do site SOLVERO. Objetivos: catálogo por sub-banda e álbum, capas corretas, links oficiais das faixas e, futuramente, um gerador de letras alinhado com a identidade musical de cada banda.

**Nota técnica:** algumas capas são atualmente carregadas por URLs da Google Drive. Antes de considerar uma atualização visual concluída, confirmar acesso público e carregamento real das imagens no GitHub Pages; idealmente alojar ficheiros estáticos próprios no repositório com autorização adequada.
